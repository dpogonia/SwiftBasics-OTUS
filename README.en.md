# Swift Basics

Console exercises from the basic OTUS course. These are playgrounds, not an app.

## Tasks

- Homework 3 — swap the minimum and maximum in an array, intersect two sets, and collect names whose password is longer than 10 characters.
- Homework 4 — index of the first repeated number.
- Homework 5 — a two-number calculator and shapes that share a base class.
- Homework 6 — a user struct, a small array of people, and a renamed person.
- Homework 7 — Apple devices, with a screen size and an iPad flag.
- Homework 8 — a sum, a tuple, an optional closure, and a leap year. This copy prints the tuple to the console.
- Homework 9 — a closure keeping an object alive, and how to break that link.
- Homework 10 — an athlete class, subclasses, and polymorphism.
- Homework GCD — print order on queues, a custom serial queue, a custom concurrent queue, and a deadlock. This is the second, fuller write-up.

## Run

```bash
git clone https://github.com/dpogonia/SwiftBasics-OTUS.git
cd SwiftBasics-OTUS
open "Homework 3.playground"
```

The other playgrounds open the same way. The queue exercise is `Homework GCD.playground`.
