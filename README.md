# Swift Basics

Консольные задачи базового курса OTUS. Это плейграунды, не приложение.

## Задачи

- Homework 3 — минимум и максимум в массиве меняются местами, пересечение двух множеств, имена с паролем длиннее 10 символов.
- Homework 4 — индекс первого повторяющегося числа.
- Homework 5 — калькулятор на двух числах и фигуры с общим классом.
- Homework 6 — структура пользователя, массив из нескольких людей, смена имени.
- Homework 7 — устройства Apple: размер экрана и признак iPad.
- Homework 8 — сумма, кортеж, необязательное замыкание, високосный год. Здесь версия, где кортеж печатается в консоль.
- Homework 9 — замыкание удерживает объект, и как эту связь разорвать.
- Homework 10 — класс спортсмена, наследники и полиморфизм.
- Homework GCD — порядок вывода на очередях, свои последовательная и параллельная очереди, дедлок. Здесь второй, более подробный разбор.

- Network — короткий разбор JSON. Запрос к сети в файле закомментирован.
- Codable — encode и decode, свои ключи, необязательные поля, даты и вложенные данные.
- Adapter, Bridge, Decorator, Facade, Proxy — структурные паттерны.

## Запуск

```bash
git clone https://github.com/dpogonia/SwiftBasics-OTUS.git
cd SwiftBasics-OTUS
open "Homework 3.playground"
```

Остальные плейграунды открываются так же. Очереди лежат в `Homework GCD.playground`.
